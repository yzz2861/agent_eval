# DUO139

This linter searches for unsafe use of `str.format` and `str.format_map`
with format strings that traverse attributes of the objects they are
given. When a format string is attacker-controlled, attribute chains in
replacement fields can reach objects the business logic never intended
to expose, e.g. `"{0.__class__.__init__.__globals__}"`.

The linter statically parses format strings, including literal escapes,
indexes, conversion flags, and nested replacement fields such as dynamic
widths. Each attribute chain is checked against a capability summary
that maps object names to the attributes a format string is permitted
to access. Format strings and object sources that cannot be determined
statically are reported separately.

The analysis is purely static: it never imports, instantiates, or calls
the objects being analyzed.

## Problematic code

```python
template = "{user.__class__}"
template.format(user=user)
```

```python
"{0:{1.prec}}".format(value, config)  # nested field traverses "config"
```

## Correct code

```python
"{user.name}".format(user=user)  # "name" is a permitted attribute
```

```python
import string

formatter = string.Formatter()
formatter.vformat(template, args, kwargs)  # validated field allowlist
```

## Rationale

Python format strings can access attributes and items of the objects
they format. Handing an untrusted format string to `str.format` or
`str.format_map` therefore exposes every reachable attribute, not just
the values the call site intended to format. Restricting replacement
fields to a permitted set of attributes keeps the formatting interface
from becoming a data exfiltration channel.

## Configuration

The linter accepts a capability summary mapping object names to the
collections of attribute names a format string may access:

```python
import dlint

linter = dlint.linters.BadFormatStringUseLinter(
    capabilities={"user": {"name", "email"}}
)
```

Objects without a capability summary, and format strings that cannot be
statically determined, are reported with their own messages so they can
be reviewed separately.
