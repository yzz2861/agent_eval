# DUO139

This linter audits the security decision made for the three finite XML
parsing entry points: `fromstring`, `iterparse`, and `parse`. It reports an
insecure compatibility fallback or an undetermined decision so the choice can
be reviewed.

Each decision is placed in one of three scopes:

* `import_build_time`: the factory or fallback is selected while the module is
  imported or built.
* `per_request`: protections are decided on each call, for example with
  `forbid_*` keyword arguments.
* `unknown`: the decision cannot be determined statically.

The snippets in this document are parsed as unexecuted source examples. They
are not imported or run by the linter.

## Problematic code

The default `defusedxml` path is safe, but the compatibility fallback loses
that protection. `DUO139` reports the real fallback import location:

```python
try:
    from defusedxml.ElementTree import fromstring
except ImportError:
    from xml.etree.ElementTree import fromstring  # DUO139
```

The same issue applies when a module alias hides the fallback:

```python
try:
    import defusedxml.ElementTree as ET
except ImportError:
    import xml.etree.ElementTree as ET  # DUO139

ET.fromstring(data)
```

## Correct code

Prefer a fallback that preserves the audited protections, or fail closed when
the protected implementation is unavailable:

```python
try:
    from defusedxml.ElementTree import fromstring
except ImportError:
    from .xml_compat import fromstring
```

Per-request decisions can be made explicit:

```python
from defusedxml.ElementTree import fromstring

fromstring(
    data,
    forbid_dtd=True,
    forbid_entities=True,
    forbid_external=True,
)
```

Import/build-time decisions can be made once:

```python
from defusedxml.ElementTree import XMLParser, fromstring

PARSER = XMLParser(
    forbid_dtd=True,
    forbid_entities=True,
    forbid_external=True,
)

fromstring(data, parser=PARSER)
```

## Reviewable summary

The linter exposes an `XMLParserSummary` after a visit. It always contains an
entry for all three entry points and groups decisions by the three scopes:

```python
linter = BadXMLParserUseLinter()
linter.visit(module_node)

print(linter.summary.render())
print(linter.summary.to_dict())
```

## Rationale

A compatibility import can silently replace a hardened parser with a parser
that does not understand the hardening options. This rule keeps the existing
`DUO135` `defusedxml` checks intact while making the fallback decision
reviewable at its actual source location.
