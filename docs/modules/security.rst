Active Content Security
-----------------------

The :mod:`pypdf.security` module provides a read-only audit of active PDF
content: document and page trigger actions, JavaScript, Launch and SubmitForm
actions, rich media, embedded files and AcroForm field actions. Auditing never
executes an action and never opens a URI, program or embedded file.
