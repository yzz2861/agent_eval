# 离线抓包校验和声明审计报告

本报告基于 dpkt 1.9.8 离线生成，把抓包软件的 checksum incorrect 提示拆成可回看的分层声明，避免把采集点卸载导致的设备未填写误判为篡改。

## 1. 采集点（假采集器）声明

| 采集器 | 方向 | 保留 FCS | TX IPv4 卸载 | TX L4 卸载 | 说明 |
|---|---|---|---|---|---|
| `COL-ING-01` | ingress | 否 | 否 | 否 | 核心交换机镜像口（入向，面向服务器 RX），镜像在网卡校验之后，链路上的校验和应为最终值 |
| `COL-EG-02` | egress | 否 | 是 | 是 | 宿主机 vSwitch 出口（出向，抓在 NIC 卸载之前），TCP/UDP/IP 校验字段可能保持 0，不能按篡改上报 |
| `COL-TAP-03` | ingress | 是 | 否 | 否 | 光纤 TAP（物理线路侧，保留 FCS），帧尾 4 字节是以太网 FCS，可做 L2 校验 |

## 2. 判定口径（三态 + 两个辅助态）

- 可校验：字段字节与重算覆盖范围全部在样本内；再分 OK（一致）与 XX（不一致，才是篡改/损坏候选）。
- 设备未填写 UN：egress 且该层声明了 TX 卸载，字段读到 0；这是 NIC 接管前占位，不是篡改。
- 样本字节不足 SH：字段或重算所需字节落在 cap_len 之外；读到 UDP/TCP 头部不代表该层可验。
- 不存在 --：该抓包点没有这一层校验字段（如驱动已剥离 FCS）。

截断只影响真实可验的层次：IP 头校验仅覆盖 IP 头，头完整即可验；L4 校验覆盖伪首部加整个分段，载荷缺口只能判 SH。
