====== Option +header_rows+

Specifies the number of leading rows that are combined to form
each column's header path. Used for parsing.

Default value:
  CSV::DEFAULT_OPTIONS.fetch(:header_rows) # => 1

The option is honored only when headers are read from the data
(that is, when +headers+ is +true+ or +:first_row+). Explicit
+headers+ given as an \Array or \String are always one-level headers.

With the default value of 1, the first row is the single header row,
and each header is a scalar value:
  str = <<-EOT
  Name,Count
  foo,0
  EOT
  table = CSV.parse(str, headers: true)
  table.headers # => ["Name", "Count"]

With a value greater than 1, the leading rows are combined into an
\Array header path for each column; columns keep their original order:
  str = <<-EOT
  Last year,,This year,,
  Amount,Count,Amount,Count,Note
  100,1,200,2,ok
  EOT
  table = CSV.parse(str, headers: true, header_rows: 2,
                         fill_headers: true)
  table.headers
  # => [["Last year", "Amount"], ["Last year", "Count"],
  #     ["This year", "Amount"], ["This year", "Count"],
  #     ["This year", "Note"]]

See {Option +fill_headers+}[#class-CSV-label-Option+fill_headers]
for how blank cells in upper header rows are treated.
