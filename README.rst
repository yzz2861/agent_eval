CVSS
====

This Python package contains CVSS v2, v3 and v4 computation utilities and
interactive calculator (for v2 and v3 only) compatible with Python 3. CVSS
(Common Vulnerability Scoring System) is an standardized method for rating
the severity of security issues on a scale from 0 (no impact) to 10 (critical).

The library is tested on all currently-supported Python versions available
via GitHub Actions but it is simple enough to run on even older versions.

Installation
------------

::

    # pip install cvss

Usage
-----

Library
~~~~~~~

.. code-block:: python

    from cvss import CVSS2, CVSS3, CVSS4


    vector = 'AV:L/AC:L/Au:M/C:N/I:P/A:C/E:U/RL:W/RC:ND/CDP:L/TD:H/CR:ND/IR:ND/AR:M'
    c = CVSS2(vector)
    print(vector)
    print(c.clean_vector())
    print(c.scores())
    print(c.severities())

    print()

    vector = 'CVSS:3.0/S:C/C:H/I:H/A:N/AV:P/AC:H/PR:H/UI:R/E:H/RL:O/RC:R/CR:H/IR:X/AR:X/MAC:H/MPR:X/MUI:X/MC:L/MA:X'
    c = CVSS3(vector)
    print(vector)
    print(c.clean_vector())
    print(c.scores())
    print(c.severities())

    print()

    vector = 'CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:N'
    c = CVSS4(vector)
    print(vector)
    print(c.clean_vector())
    print(c.scores())
    print(c.severities())

Approval explanation (CVSS 4.0)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

When a risk rating is changed, the approval helper explains which metric changes
are jointly responsible for moving the score across a gate. Given two complete
CVSS 4.0 vectors it returns every inclusion-minimal set of changes whose joint
application crosses a caller supplied threshold, each with the full ordered
vector and its rounded score so the original calculator can be used to re-check
it. No external solver is used; the search is a bounded enumeration.

Metrics that must always be applied or rejected together are declared with
``coupled_groups``. Scores, modified metric inheritance and the round half up
rounding are taken straight from the CVSS4 calculator. If the evaluation budget
is reached, ``complete`` is False and only the conclusions that were actually
proven are returned.

.. code-block:: python

    from cvss import CVSS4

    original = (
        "CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:L/SA:H/"
        "E:A/CR:H/IR:H/AR:L"
    )
    reviewed = (
        "CVSS:4.0/AV:P/AC:L/AT:N/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:L/SA:H/"
        "E:U/CR:H/IR:H/AR:L"
    )

    result = CVSS4(original).explain_approval(reviewed, 6.9)
    print(result.original_score, result.reviewed_score, result.complete)
    for group in result.minimal_groups:
        print(group.metrics, group.score)
        print(group.vector)

    # Metrics that must move together can be coupled by the caller.
    result = CVSS4(original).explain_approval(
        reviewed, 6.9, coupled_groups=[("AV", "E")]
    )

Interactive calculator
~~~~~~~~~~~~~~~~~~~~~~

For interactive calculator run the following:

::

    $ cvss_calculator

For help on the calculator options run:

::

    $ cvss_calculator --help

Testing
-------

For extensive testing, the test vectors were generated using official
JavaScript generators and `cvsslib <https://github.com/ctxis/cvsslib>`_.

To run all tests using all supported versions of Python 2 and Python 3 installed:

::

    $ tox
    $ tox -e py311   # Run tests using a specific version of Python
